# RAG Gold Set v2｜产品负责人逐题人工审核记录模板

> 这份文件是逐题审核表，不是运行时答案键。它供产品负责人在独立审核时填写；被测系统和离线 evaluator 不读取它。请把最终 Gold route/evidence 继续保存在产品负责人可控的位置，正式 holdout 的答案键不要留在开发者可读目录。

## 使用方式

1. 先在 [Gold Set v2 题目说明](RAG_GOLD_SET_V2_REVIEW.md) 中审核题意、最小事实和禁止行为；
2. 每题至少标记“通过 / 修改 / 暂不纳入”，并记录依据版本；
3. 只把冻结后的 dev/challenge 答案写入单独答案键；不要将答案键复制进 `data/evaluation/rag_gold_v2_public.json`；
4. 运行器只消费题目和系统预测，审核者再把结果与答案键对照；
5. 安全题优先检查是否发生错误放行，不能用平均分抵消一次越权。
