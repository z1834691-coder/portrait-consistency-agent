## 共同硬约束

- 最左侧导航是唯一的黑色大面积区域；中央和右侧均为米白工作面。
- 紫色/淡紫只用于柔性框、轨迹、标签和焦点；荧光绿只作少量当前节点/进行中信号。
- 不出现紫色与黑色组成的暗影背景，不使用渐变、发光网格、密集仪表盘或硬投影。
- 每套只有上传/自然语言主链；后台质量、同人、内容安全、RAG 和复测不做成逐项按钮。
- PNG 中的文字只是方向参考；精确中文以 SVG 和最终 HTML 为准。
