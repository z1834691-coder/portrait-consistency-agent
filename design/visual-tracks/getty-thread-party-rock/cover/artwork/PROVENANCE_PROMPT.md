# K00 sourced artwork provenance

These are sourced historical artworks, not Image 2 generations. The local JPEGs were
downloaded from the Wikimedia Commons `Special:FilePath` endpoints documented in
`SOURCES.md` on 2026-09-03 and resized to a 900px long edge for an editable visual
prototype. Preserve the artist/title, source page and regional public-domain caveat
when replacing or exporting any card. Do not treat the images as user portraits,
model output, evidence, or a license guarantee for production.
